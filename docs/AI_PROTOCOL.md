# AI_PROTOCOL — 对话协议与提示词规范

> v1.0 · 2026-07。这是"AI 驱动对话"的接口契约，写代码与写提示词都以此为准。

## 1. 协议总览（结构化标记文本）

AI 每次返回**纯文本**，用行标记切分三种内容：

```
（第一段 = 台词，可多行，逐字打字机显示）

[选项]选项文案一
[选项]选项文案二
[选项]选项文案三

[事件]事件编号        ← 可选，出现即触发预制事件
[情绪]happy           ← 可选，预留（v1 可不做，头像/音乐反应用）
```

规则：
- 台词：所有非标记行。多行按顺序播放。
- `[选项]`：每行一个，1–4 个。玩家点击后该行作为"玩家说的话"回传 AI。
- `[事件]`：最多一个；触发事件演出，演出后回到对话。
- **容错**：AI 格式不规范时，游戏端仍显示台词；无 `[选项]` 时给默认选项「（继续）」。解析失败绝不让游戏卡死。
- 远期升级：协议换为 JSON（`{"reply","options","event","emotion"}`），解析层预留接口即可切换。

## 2. 请求上下文结构（每次调用）

```
system: 全局世界观 + 剧情状态 + 角色扮演规则 + 禁令清单 + 格式要求
system: 当前 NPC 人物卡
user:   本轮剧情状态更新（可选，如"好感度+1"）
assistant: 最近对话历史（最多保留 10 轮，超出裁剪）
user:   玩家本轮输入（选项文本 / 开场白）
```

- **token 控制**：历史限 10 轮 + 人物卡限 200 字内 + 世界观限 300 字内。
- **状态注入**：关键剧情状态（已触发事件、好感度）每次调用前拼进 system。

## 3. 系统提示词模板（草案，DSH 负责细化）

```
【角色】你是《治愈小镇》里的 {NPC名}，{一句话人设}。
【世界观】{300字内小镇设定}
【风格】平淡温柔治愈的中文口语，说话自然不书面，不堆砌辞藻，每句 30 字以内。
【记忆】你记得最近发生过的事：{剧情状态摘要}。你认识主角：{与主角关系}。
【输出格式】先输出你的台词（可多行），需要让玩家选择时在单独一行输出 [选项]xxx，
最多 4 个选项，用词口语化；对话中若应该触发剧情事件，在最后加一行 [事件]事件编号
（只能使用已提供的事件列表）。
【禁令】禁止：剧透未发生剧情；提到设定中不存在的人物/地点/事物；打破第四面墙；
让主角或 NPC 死亡/重伤；输出 [选项] 以外的标记格式；输出超出 4 个选项。
【事件池】{可用事件编号与一句话描述}
```

## 4. 防脱轨三层防护

1. **提示词禁令**：上节"禁令"清单，随版本迭代补充实际翻车案例。
2. **关键词过滤**：客户端对 AI 输出做关键词/正则拦截（脏词、危险内容、标记滥用），命中则丢弃该段并改用兜底。
3. **兜底台词**：每个 NPC 预写 3–5 条万能台词（本地 JSON），异常时轮换使用。

## 5. 失败兜底流程

```
发起请求 → 失败/超时(8s) → 自动重试 1 次 → 仍失败 → 显示兜底台词 + 轻提示"网络不太稳"
                                                                      → 对话框正常结束，不卡死
```

## 6. 上下文样例（一次真实请求，供调试比对）

```
system: 【角色】你是咖啡馆老板林叔，52 岁，小镇情报中心，说话慢悠悠爱唠叨。
【世界观】云杉镇是一座河边小镇，三百多口人，以咖啡和手作面包闻名……
【记忆】今天早晨河边传来怪声，你听说了但没去看。主角小夏是你的常客。
【输出格式】……
【禁令】……
【事件池】[river_shadow] 河边黑影事件；[lost_key] 杂货店丢钥匙事件

user: 林叔，早上好，今天有什么新鲜事吗？

assistant(期望): 哟，小夏来啦。今早倒是有点动静，河那边……怪怪的。
[选项]河边怎么了？
[选项]给我来杯招牌咖啡
[选项]最近店里生意怎么样？
```

## 7. 人物卡格式（存 data/npcs/*.json，DSH 起草、人工审核）

```json
{
  "id": "uncle_lin",
  "name": "林叔",
  "role": "咖啡馆老板",
  "persona": "慢悠悠、爱唠叨、刀子嘴豆腐心，60字内",
  "secret": "年轻时是乐队贝斯手，没人知道",
  "relation": "主角的常客与长辈",
  "style": "每句短，爱用'哟''嘛'，常问主角吃饭没",
  "forbidden": ["不提贝斯手身份，除非剧情解锁", "不说网络流行语"],
  "fallback_lines": ["（林叔擦了擦杯子）……嗯，今天风挺舒服的。"]
}
```

## 8. 提示词维护流程

- 每次"AI 翻车"（脱轨/格式错/语气崩）→ 记录到 `docs/AI_ISSUES.md`（DSH 维护）→ 批量改进提示词或过滤器。
- 禁止在聊天里口头修复后遗忘；一切修复落文档。

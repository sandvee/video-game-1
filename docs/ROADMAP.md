# ROADMAP — 里程碑 M0–M6

> 总周期约 16 周（2026-07 启动，11 月前后发布）。零碎时间开发的纪律：**每周末都有"能给人看的东西"**；忙时里程碑滑动，不删除。

## 总览

| 里程碑 | 周期 | 交付物（能给人看的） | 完成定义（DoD） |
|---|---|---|---|
| M0 地基 | 第 1 周 | 空项目能跑 + AI 连通 + 首批内容草案 | 浏览器打开页面显示像素测试场景；控制台能调通 DS API 返回一句话；6 角色草案/地图布局/3 套配色已出 |

## M0 任务卡（第 1 周，两周内启动）

每人独立可做的小块：

- [ ] T1 建 GitHub 私有仓库 + 克隆到两台电脑（编程方）
- [ ] T2 Day-1 spike：浏览器 fetch 调 DS API 返回一句话，验证 CORS（编程方；被拦则写 15 行本地代理）
- [ ] T3 注册 DeepSeek 开放平台 + 充值约 10 元 + 拿到 API key（两人，先注册者做）
- [ ] T4 安装 Tiled + LibreSprite，各画一张 8x8 测试图摸清导出（美术方）
- [ ] T5 审核 NPC 角色草案（docs/drafts/NPC_DRAFTS.md，**草案已出**）→ 确认后落 data/npcs/*.json
- [ ] T6 确认小镇布局草案（docs/drafts/MAP_DRAFTS.md，**草案已出**）→ 美术方在 Tiled 里画第一版
- [ ] T7 从 3 套配色中选 1 套（docs/drafts/PALETTES.md，**草案已出**）→ 落 docs/DESIGN.md
- [ ] T8 观察记录：谁更擅长面对报错、谁更坐得住画图 → 定分工（D31 落地）

M0 结束标准：上述全部完成，分工确定，进入 M1。

## 每周工作模式（建议）

- 每人每周认领 1–2 张任务卡，粒度保证 **30 分钟内能推进一格**。
- 完成 → 开 PR → 对方 review → 合并 → 在 docs/ROADMAP.md 勾选。
- 随缘同步没问题，但勾选和 PR 必须留痕。
- 卡壳 >30 分钟 → 把报错/现象原文丢给 DSH。

## 范围砍削清单（时间不够时按序砍）

1. 先砍：多余 BGM（留 1 首）、NPC 动画帧数（NPC 转 2 向）
2. 再砍：事件数量（12→8）、杂货店/河边等次区域
3. 底线（不可砍）：AI 对话闭环（M3）、一个完整事件、存档
   —— 即使砍到只剩"一个咖啡馆 + 3 个 NPC + 4 个事件"，也要是**能发布、AI 对话惊艳**的游戏。

## 风险与对策速查

| 风险 | 触发信号 | 对策 |
|---|---|---|
| 学业压垮节奏 | 连续 2 周零提交 | 降速模式：每人每周只做 1 张小卡，保活不保量 |

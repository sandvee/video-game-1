# DESIGN — 游戏设计文档（GDD）

> 版本 0.1 · 2026-07 · 基于需求访谈结论

## 1. 核心概念

- **标题**：暂定《治愈小镇》（代号，正式名待定，可让 DSH 出候选）
- **类型**：2D 像素风、单人、纯叙事探索 RPG（无战斗）
- **时长**：单局 30 分钟
- **调性**：治愈温馨、平淡温柔、中文文本
- **核心卖点**：所有对话与事件触发由 AI 实时驱动，每次游玩台词、选项、事件组合不同
- **世界观（已定稿）**：《云杉镇》——河边小镇，三百多口人，以「树影咖啡馆」与手作面包闻名。主角小夏（20 岁，大一学生）暑假回乡帮舅舅打理咖啡馆。基调平淡温柔；悬念钩子：每年夏天河边会出现淡淡的光（只做氛围，不破坏治愈感）。

## 2. 玩法循环

```
进入小镇 → 自由走动 → 与 NPC 对话（AI 生成台词+选项）
        → 对话中 AI 触发预制事件 → 事件推进剧情/改变状态
        → 关键节点自动存档 → 30 分钟后走向结局 → 再来一局
```

无战斗、无成长数值。唯一"系统"是：AI 对话、事件调度、好感度状态。

## 3. 主角（已定稿）

- **小夏**，20 岁，大一学生，暑假回乡帮舅舅（林叔）打理「树影咖啡馆」。
- 背景故事写进全局提示词，AI 对话会自然引用。
- 主角 32x48，4 方向 × 4 帧完整动画。

## 4. 小镇（单张地图）

- **规模**：约 40x30 格，32x32 地砖。
- **布局草案已确认**：见 docs/drafts/MAP_DRAFTS.md（40x30 区域坐标表 + Tiled 图层约定）。
- 可考虑 1 个室内场景（咖啡馆内部）验证场景切换。
- 建筑/树木/栅栏等物件用免费素材包，角色全部自制。

## 5. NPC（6 个，人物卡已定稿）

- 人物卡存 data/npcs/*.json（6 张）：林叔、苏黎、老周、阿禾、小满、陈婆婆。
- 每张卡：性格、说话风格、秘密/愿望、与主角关系、禁止事项、兜底台词。
- 角色动画：NPC 4 方向 × 2 帧简化动画。
- 建议构成（草案）：咖啡馆老板（情报中心）、青梅竹马、神秘旅人、退休教师、杂货店主、河边老渔夫。

## 6. AI 架构（三层，逐层升级）

| 层 | 内容 | 版本 |
|---|---|---|
| L1 对话 | 固定剧情骨架，AI 生成台词与选项（结构化文本） | **v1 做** |
| L2 状态 | 好感度/剧情状态入存档，AI 对话参考历史 | **v1 做** |
| L3 事件调度 | AI 在预制事件池中选择触发时机/顺序，主线由 AI 决定 | v1 埋 `[事件]` 标记，远期做 |

关键约束：**AI 不生成地图/立绘等美术，只调度与编排预制内容**。

## 7. 事件系统

- 事件 = 你们手工编写的剧情脚本（8–12 个），存 JSON。
- 触发方式：对话中 AI 输出 `[事件]事件编号` 标记 → 游戏加载并演出该事件。
- 事件脚本字段（草案）：`id`、`前置条件`、`演出文本（可含多个场景步）`、`执行后状态变更`、`好感度影响`。
- 事件演出期间 AI 暂停，演出结束回到 AI 对话（防止 AI 与事件打架）。

## 8. 存档

- 自动存档（对话后/事件后）+ 手动存档（菜单）。
- 内容：剧情进度、好感度、已触发事件、近期对话摘要（可选）。
- 技术：浏览器 localStorage（后期如需跨设备再换）。

## 9. UI（经典 JRPG 底部对话框）

- 底部对话框 + 打字机效果 + 选项列表（最多 4 项）+ NPC 头像。
- 标题画面、菜单（存档/读档/设置）。
- 点击/空格推进，Esc 打开菜单。

## 10. 美术方向

- **像素规格**：地砖 32x32，角色 32x48，整数倍放大显示。
- **配色（已选）**：方案 A「奶油与青草」（见 docs/drafts/PALETTES.md）。
- **素材策略**：场景物件用免费素材包（OpenGameArt / itch.io 免费包），主角与 NPC 全自制。
- **动画量**：主角 4向×4帧；NPC 4向×2帧。
- **音效**：Freesound 免费音效；音乐用 Suno 生成 3 首 BGM。

## 11. 风险表

| 风险 | 概率 | 对策 |
|---|---|---|
| AI 回复质量不稳定/脱轨 | 高 | 三层防护（禁令+过滤+兜底）；提示词迭代测试 |
| 浏览器直连 API 被 CORS 拦截 | 已排除 | spike 已在本机验证直连成功，无需本地代理 |
| API key 暴露（发布后） | 中 | 个人 Demo 可接受；itch.io 公开前加代理或限制 |
| 自制美术工作量爆表 | 高 | 场景用免费素材；NPC 动画简化；范围砍削清单 |
| 学业忙断档 | 高 | 忙时降速不放弃；任务粒度 30 分钟可推进一格 |
| 两人想法分歧 | 中 | 决策一律落文档，DSH 中立仲裁 |

## 12. 明确不做（v1）

- 自由文本输入（v2 加）
- 多地图大世界
- 跨局完整记忆
- 自定义主角

# CONTEXT — 项目背景与约定

> 本文件是项目的"总入口"，所有新人（包括两个月后的你们自己）先读这里。

## 项目一句话

治愈系 AI 小镇对话 RPG：纯叙事探索玩法，NPC 对话由 DeepSeek v4 flash 实时生成，每次游玩台词与事件组合都不同。30 分钟单局。

## 团队

- 2 人（清华，零编程/美术基础起步，暑期+学期零碎时间开发）
- 分工：**M0 结束后再定**。参考分工：一人主攻"代码集成 + AI 系统"（面对报错、验收 DSH 代码），一人主攻"美术 + 剧情文案"（画图、审人物卡）。两人都需能读懂全部代码。
- 同步节奏：随缘随时聊，但**一切决策与任务落文档**，GitHub 提交历史为准。

## 技术栈（已定，2026-07）

| 环节 | 选择 | 说明 |
|---|---|---|
| 引擎 | **无引擎** | HTML5 Canvas + 原生 JavaScript，无框架无构建工具 |
| 地图 | Tiled（免费） | 可视化画地图 → 导出 JSON → 游戏加载 |
| 像素画 | LibreSprite（免费，Aseprite 的开源版） | 图层/动画/精灵表导出 |
| 版本管理 | Git + GitHub 私有仓库 | GitHub Desktop 图形界面 |
| 运行时 AI | DeepSeek API（v4 flash） | OpenAI 兼容，成本约几分钱/局 |
| 开发辅助 | DSH（DeepSeek Harness）+ DS v4 flash | 写代码/写文案/维护文档 |
| 音乐 | Suno（免费额度）AI 生成 | 3 首：咖啡馆/白天/傍晚 |
| 音效 | Freesound 等免费站 | 行走、点击、事件音效 |

## 核心约定

1. **语言**：游戏内全部中文；代码注释中文；文档中文。
2. **平台**：Windows PC（开发期即浏览器）。
3. **预算**：0 元。唯一例外：DeepSeek API 充值（最低约 10 元，够几百局）。
4. **对话协议**：结构化标记文本（见 AI_PROTOCOL.md），不使用 JSON（预留升级路径）。
5. **防 AI 脱轨**：提示词禁令 + 关键词过滤 + 兜底台词，三层防护。
6. **范围纪律**：时间不够就砍内容（先砍音乐、再砍美术细节、最后砍事件），不砍"AI 对话惊艳"这条底线。
7. **学业冲突**：忙时降速不放弃，里程碑滑动不删除。
8. **代码质量**：DSH 生成代码后，人必须通读一遍再合并；改动走 PR 互查。

## 3. 碰撞规则

- 阻挡：水面、树林、所有建筑墙体、钟楼。
- 可走：石板路、广场、草地开阔处、栈道。
- 门 = 触发点（见下），走到门口按互动键进室内。

## 4. Tiled 图层约定（代码 M1 按此读取）

| 图层 | 类型 | 内容 |
|---|---|---|
| `ground` | tile 层 | 草地/石板/水面/栈道等地面 |
| `objects` | tile 层 | 建筑、树、花坛、长椅、钟楼 |
| `collision` | tile 层（隐藏） | 纯阻挡标记（代码碰撞检测用） |
| `events` | 对象层 | 触发点矩形：`door_cafe`、`river_light`、`bench_bread`、`old_zhou_fishing`、`spawn` |

## 5. Tiled 操作步骤

1. Tiled → 新地图：40×30，tile 宽高 32×32，方向"正交"。
2. 依次建上面 4 个图层（顺序：ground 最底 → objects → collision → events 最顶）。
3. 按坐标表放 tile；`collision` 层用一个醒目的纯色 tile 标出阻挡格。
4. `events` 对象层用"插入矩形"画触发点，命名如 `door_cafe`。
5. 保存为 `assets/maps/town.tmx`；导出 JSON（文件 → 另存为 → Tiled JSON，选"内嵌图块集"更省事）得到 `town.json` 给游戏加载。

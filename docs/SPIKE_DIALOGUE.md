# 对话协议服从率测试（决策 D49 的执行）

> 目的：验证 v4 flash 输出对话时对 `[选项]` / `[事件]` 标记的服从率，决定 M3 对话协议用「标记」还是「JSON」。
> 背景：导演测试 v1 已证明 v4 flash 对 `[事件]` 标记服从性差（11 步 7 次未按格式输出）——对话协议的标记**不能想当然，必须实测**。

## 测试方法（spike/dialogue-test.html）

1. 浏览器打开 `spike/dialogue-test.html`，填桌面 `API.txt` 的 key。
2. 点「跑 2 段对话（林叔+苏黎）」。
3. 读日志与汇总。

**测试内容**：每段对话 6 轮。系统提示词 = 人物卡 + 世界观 + 格式要求 + 禁令（与 AI_PROTOCOL.md 一致）；玩家输入 = 脚本台词，若 AI 上一轮给了选项则自动选第一个（模拟真实玩法）。统计每轮：

- **解析率**：回复能否解析出台词或选项（任意内容可用）
- **选项合规率**：出现 `[选项]` 的回合中，格式正确且 1-4 个的比例
- **违规**：异常标记（`【选项】`、未知 `[xxx]`）、选项超 4 个、有选项无台词、事件 id 不在池内

## 判定标准（达到即沿用标记协议）

| 指标 | 目标 |
|---|---|
| 解析率 | ≥95% |
| 选项合规率（有选项的回合） | ≥85% |
| 违规合计（2 段对话） | ≤2 次 |

- ✅ 达标 → M3 沿用 `[选项]`/`[事件]` 标记协议（解析层保持宽容）。
- ⚠ 不达标 → M3 改用 **JSON 协议**（`{"reply":"...","options":[...],"event":"..."}`），解析失败时回退到"纯文本当台词 + 默认「（继续）」"。

## 成本参考

2 段 × 6 轮 = 12 次调用 ≈ 8-10k tokens ≈ 0.02-0.05 元。

## 结果记录

- 结果与判定写入 docs/AI_ISSUES.md 与 decisions.md（D50）。
- 无论结果如何，**M3 解析层都按"多格式宽容"实现**（JSON → 标记 → 纯文本回退），架构不受本次结论影响。
